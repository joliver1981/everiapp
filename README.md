# AIHub Builder — Releases

This repository hosts release downloads for the **AIHub Builder** (the desktop app for building AI-powered applications) and the **AIHub Agent** (the deployment service installed on target servers).

- Download the latest version from the [Releases page](../../releases) or at the [AIHub Marketplace](https://aihub-marketplace.vercel.app/download).
- The Builder currently ships for Windows; macOS and Linux builds are planned.
