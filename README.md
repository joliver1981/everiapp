# EveriApp — Releases

This repository hosts release downloads for the **EveriApp Builder** (the
desktop application for building AI-powered apps) and the **EveriApp Agent**
(the deployment service installed on target servers).

- Download the latest version from the [Releases page](../../releases) or at the
  [EveriApp Marketplace](https://aihub-marketplace.vercel.app/download).
- The Builder currently ships for Windows; macOS and Linux builds are planned.
